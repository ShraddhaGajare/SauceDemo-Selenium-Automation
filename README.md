
# SauceDemo Selenium Automation Testing

Automated web application testing project using Python,
Selenium WebDriver, Pytest, and Google Chrome.

## Application Under Test
https://www.saucedemo.com/

## Test Coverage
- Login page UI verification
- Positive and negative login testing (planned)
- Product listing and sorting (planned)
- Shopping cart functionality (planned)
- Checkout validation (planned)

## Tools
- Python
- Selenium WebDriver
- Pytest
- Chrome
- Git and GitHub

## Run Tests
pip install -r requirements.txt
python -m pytest -v -s
